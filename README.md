# Notebook Tahlil Digital

Kitab tahlil digital bergaya klasik dengan warna hijau, emas, dan kertas krem.

## Fitur
- Navigasi halaman dan daftar isi.
- Posisi bacaan terakhir disimpan di perangkat.
- Pengaturan ukuran tulisan Arab.
- TTS Arab dari suara yang tersedia di perangkat/browser.
- Pilihan audio qari untuk bagian surah yang didukung.
- Layout responsif untuk HP Android dan desktop.

## Deploy ke Vercel
Proyek ini berupa HTML/CSS/JavaScript statis, tanpa proses build. Import repositori ini di Vercel dengan:
- Framework Preset: Other
- Build Command: kosongkan
- Output Directory: .
- Root Directory: .

Catatan: ketersediaan TTS Arab bergantung pada suara yang terpasang di perangkat. Audio qari membutuhkan koneksi internet. Periksa teks dan tajwid bersama guru/ustaz setempat.
